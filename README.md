# ReviewVex — O pulso dos games

Site de notícias e reviews de games em português brasileiro.

**Demo live:** [https://tokitest.grok.me](https://tokitest.grok.me)

Este repositório foi criado a partir do site de demonstração ReviewVex.

## Seções

- Destaques e Plantão
- Games, Entretenimento, Otaku, Indies
- Análises e Indica
- Agenda e Ranking
- Consoles (PlayStation, Xbox, Nintendo)
